三宫格 v1｜嵌入现有项目说明
对应视觉参考：
trio-template-v2-1-thin-border.html

一、模板定位

模板名称：三宫格

用途：
- 一张图展示 3 部乙抓
- 信息量介于完整版与简略版之间
- 每部保留足够大的 BK 和较完整的 Repo
- 适合“三部推荐 / 三部总结 / 同声优三作 / 最近三听”等场景

固定结构：
- 1080 × 1440
- 3:4 竖版
- 3 部作品纵向排列
- 每部都是：
  左侧 BK
  右侧 CV + RJ
  右侧现价 + 总评分
  右侧 Repo

不包含：
- 社团
- 系列
- 关键词
- 原价 / 史低
- 多项评分
- 作品标题（当前版本不放）

二、整体外框

继续沿用现有完整版视觉体系：

- 外围实线框：inset 16px
- 内围虚线框：inset 30px
- 背景使用现有主题渐变 / 网格纹理
- 右下可保留极淡 watermark

不要新增第三层外围框。

三、三部作品总体布局

模板有效内容区域：
大约 inset 58~62px。

三部纵向排列：
- 3 行
- 行间留少量分隔空间
- 每部高度约 410~420px

单部区域：
- 左右结构
- 左侧 BK 宽约 400px
- 右侧为信息区
- 左右间距约 24px
- 单部内部 padding 约 16px 20px

每部区域现在有：
- 很浅的白色半透明底
- 极轻粉 / 薄荷晕染
- 1px 浅色实线描边
- 圆角约 26px

注意：
三个大框只保留一层细实线描边。
不要再叠加虚线、双框、厚边框。

四、单部装饰

每个大框内部加入轻杂志装饰：

左上：
✦ ─────
- 粉色系
- 很浅
- 短线
- 不加编号

右下：
───── ✦
- 薄荷绿色系
- 很浅
- 与左上形成非对称呼应

不要：
- 01 / 02 / 03 编号
- 大面积花边
- 复杂角花
- 额外散点

五、三部之间的分隔

三块之间继续保留：
粉色虚线 + 中间小五角星 + 薄荷绿虚线

保持轻量。
不要让分隔线与大框实线描边视觉冲突。

六、BK

最终尺寸参考：
约 400 × 300
比例固定：
4:3

BK 现在已经放大，目的：
- 减少上下悬空感
- 让封面成为每部作品的视觉主角
- 仍保留右侧足够 Repo 空间

BK 不需要继续放大到 430~450px。
否则会明显压缩右侧文字宽度。

视觉：
- 有图：
  白色 2~3px 描边
  外层极浅主题色描边
  轻阴影
  圆角约 20px
- 无图：
  浅底
  虚线边框
  “点击上传 BK”

七、BK 编辑交互

沿用现有项目统一逻辑。

PC：
- 无图：点击 BK 上传
- 有图：点击 BK 可替换
- hover 有图 BK 显示顶部工具条

工具条：
【完整】【裁切】【编辑】【移除】

对应：
- 完整：contain
- 裁切：cover
- 编辑：进入现有图片编辑器
- 移除：清除当前 BK

手机：
- 无图：点击 BK 上传
- 有图：点击 BK 显示 / 隐藏工具条
- 如果项目已有移动端“上传”按钮方案，可继续复用

不要为三部作品创建三套独立 Canvas。
继续复用现有 imageEditModal / imageEditCanvas。

建议：
activeTrioIndex = 0 / 1 / 2

编辑完成：
写回该格最终扁平化图片。

八、右侧第一行：CV + RJ

结构：

CV  一条ひらめ            RJ  RJ01152097
----------------------------------------

要求：
- CV 和 RJ 同一行
- CV 在左
- RJ 在右
- 标签用主题 accent 色
- 值用深色 ink
- 不要做成两个大输入框
- 不要做胶囊
- 下方一条很淡的虚线分隔

CV：
- 可编辑
- 字号约 18~19px
- 标签和值同行

RJ：
- 可编辑
- 左对齐
- 正常宽度容纳 RJ + 8 位数字
- 过长再适度扩展
- 不要留大块无意义空白

九、右侧第二行：现价 + 总评分

结构：

现价  ¥154         总评  ★★★★☆  4.0

整体放在一条极浅色 summary strip 中。

summary strip：
- 非厚重卡片
- 极浅粉→薄荷渐变
- 圆角约 16px
- 高度约 54~58px

现价：
- 只保留“现价”
- 不显示原价 / 购入价 / 史低
- 金额字体可以稍大
- 推荐 accentDeep

总评分：
- 星级点击
- 1~5 星
- 同时显示数字：
  例如 4.0 / 5.0

建议数据：
rating: 4

显示：
★★★★☆ 4.0

十、Repo

Repo 全部位于右侧。
不要放到 BK 下方，也不要横跨整个单作区域。

位置：
右侧中下半部分。

视觉：
- 左侧主题色细竖线
- 小爱心
- 顶部小字 REPO
- 无完整大圆角框
- 文字直接排版

建议：
- 高约 150~160px
- 字号约 15~16px
- line-height 约 1.55~1.6
- 支持约 5~7 行自然阅读

当前 Demo maxlength 可作为参考，但正式项目不要过早把字数限制卡太死。
如果导出必须防溢出，建议按实际画布高度做视觉截断或提示。

十一、推荐数据结构

trio:
{
  cells: [
    {
      cover: "",
      coverFit: "cover",
      cv: "",
      rj: "",
      price: "",
      rating: 0,
      repo: ""
    },
    {
      ...
    },
    {
      ...
    }
  ]
}

固定 3 格。

coverFit：
- contain
- cover

rating：
建议用 number 1~5。

十二、RJ 一键导入

这个模板很适合复用现有 DLsite RJ 导入。

每格 RJ 可以自动导入：

- BK
- CV
- 现价（如果现有接口数据可稳定提供）

不要导入：
- 社团（模板没有）
- 关键词
- 多余字段

建议规则：

1. RJ 为空 → 跳过
2. RJ 有效 → 请求作品数据
3. BK 为空 → 自动填 BK
4. CV 为空 → 自动填 CV
5. 用户已填 CV → 默认不覆盖
6. 现价为空且接口有可靠价格 → 自动填现价
7. 单格失败不影响其他格

可做模板外按钮：
【按RJ号一键导入】

一次只 3 格，并发压力很小。

十三、可考虑的模板外工具

当前第一版建议只保留真正有用的：

- 按RJ号一键导入
- 只清空Repo

后续若需要再加：
- 交换 1 / 2 / 3 顺序
- 从我的收藏选择 3 部

不要为了模板独立再做复杂控制台。

十四、作品顺序

后续最好支持：
- 拖拽排序
或
- 上移 / 下移

因为“三部推荐”类场景经常会需要调整顺序。

v1 不是必须，但数据结构请保持 cells[0..2] 独立，方便后续加。

十五、主题适配

所有颜色尽量读取现有主题变量。

建议映射：
- ink
- muted
- accent
- accentDeep
- mint / dash
- line
- coverBg

三作版的：
- 左上装饰：accent
- 右下装饰：mint
- 单块细描边：line
- summary strip：accent + mint 的极浅混合
- Repo 左线：accent
- 星级：accent

不要写死成唯一粉色主题。

十六、导出 PNG

这是最容易漏掉的地方。

如果项目现有导出采用 Canvas 手绘，
必须同步实现三作版，而不是只做 DOM CSS。

Canvas 需同步绘制：

1. 整体 1080×1440
2. 外围实线 + 内围虚线
3. 3 个单作区域
4. 单作浅底色
5. 1px 细实线描边
6. 左上粉色 ✦ + 短线
7. 右下薄荷绿短线 + ✦
8. 三块之间的粉绿虚线 + 中央小星
9. 400×300 的 4:3 BK
10. BK 白边 / 轻阴影
11. CV + RJ 第一行
12. 第一行下方淡虚线
13. 现价 + 总评 summary strip
14. 星级 + 数字评分
15. Repo 左竖线 + 小爱心 + REPO + 正文
16. watermark（如现有模板统一有）

不要导出：
- hover 图片工具条
- 上传控件
- 模板外操作按钮
- 编辑状态高亮
- input / textarea 边框

十七、手机端

模板本身仍保持 1080×1440。
手机端只整体缩放预览，不改成纵向 6 段或其他重排。

重点保证：
- 3 部布局比例不变
- 手机点击 BK 可正常操作
- 星级按钮触控区足够
- textarea 编辑时不要破坏模板宽度
- 模板外按钮适配手机宽度
