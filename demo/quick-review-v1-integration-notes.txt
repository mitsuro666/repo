速评版 v1｜嵌入现有项目说明
对应视觉参考：
quick-review-template-v4-2-star-lines.html

一、模板定位

模板名称：速评版

用途：
- 一次展示 12 部乙抓
- 快速记录 / 一句话 Repo / 最近听过合集
- 信息密度高于完整版和九宫格，但仍保证 BK 和短评可读性

固定结构：
- 1080 × 1440
- 3:4 竖版
- 2 列 × 6 行
- 无大标题
- 每条包含：
  1. BK
  2. CV
  3. RJ号
  4. 一句话 Repo

不加入：
- 作品标题
- 社团
- 评分
- 价格
- 关键词
- 大标题

二、整体视觉

继续复用完整版主题系统和外围结构：

- 背景渐变 / 网格纹理沿用现有主题
- 外围实线：
  inset:16px
- 内围虚线：
  inset:30px
- 不再额外增加第三层外围框

每条速评卡：
- 浅色卡片底
- 轻描边
- 很轻的阴影
- 圆角约 22~24px
- 避免做成厚重的独立“大卡片”

三、12条布局

最终为：
2列 × 6行

原因：
DLsite 大部分 BK 为 560×420，即 4:3。
3列会导致 BK 太小，也会压缩 Repo 阅读空间。

每条卡片结构：

上装饰线
↓
左：4:3 BK
右：
  CV + 名字（同行）
  虚线分隔
  一句话 Repo
↓
下装饰线

四、上下装饰线

最终采用纯 CSS，不使用图片素材。

视觉：
- 左半段粉色细虚线
- 中间一个实心五角星
- 右半段薄荷绿色细虚线
- 上下各一条
- 不要额外散点、小圆点、菱形

五角星：
建议用 clip-path polygon 实现。

注意：
之前测试过“圆点 + 伪元素位移”的方案，缩放后出现散落点，已废弃。
不要恢复那套实现。

五、BK

比例：
固定 4:3

推荐参考：
- 单条左列宽约 190px 左右
- BK 尽量吃满左侧区域
- 避免上下出现大量无意义空白

有图时：
- 白色 2~3px 描边
- 外层一圈极浅主题色
- 轻阴影
- 圆角约 16~17px

无图时：
- 虚线边框
- 文案：点击上传 BK

六、BK 上传与编辑交互

核心要求：
点击 BK 区域始终与图片上传/编辑相关。

PC端：

1. 没有图片
点击 BK
→ 打开图片上传

2. 已有图片
点击 BK
→ 仍可打开图片上传，作为替换图片

3. 已有图片时
鼠标 hover 到 BK
→ 显示顶部工具条

工具条按钮：
【完整】【裁切】【编辑】【移除】

默认不常驻显示。

按钮对应正式项目功能：
- 完整：object-fit contain / 完整显示
- 裁切：object-fit cover / 铺满裁切
- 编辑：打开现有图片编辑器
- 移除：清除该格 BK

手机端：

1. 没有图片
点击 BK
→ 直接上传图片

2. 已有图片
BK 右下区域：
【上传】 + RJ号

【上传】
→ 替换当前图片

3. 已有图片
点击 BK 主体
→ 显示 / 隐藏顶部工具条

这样手机不会因为 hover 不存在而无法操作。

七、图片编辑器

不要给 12 张 BK 创建 12 套 Canvas。

复用项目现有 imageEditModal / imageEditCanvas。

推荐逻辑：

activeQuickReviewIndex = 当前点击的格子

点击“编辑”
→ 将该格 BK 加载进现有修图器
→ 马赛克 / 模糊 / 贴纸等继续复用现有功能
→ 完成
→ 把最终扁平化图片写回该格

速评版 v1 建议每格只保存最终成品图。

不要为 12 张图片分别保存完整：
- 原始图
- mosaic mask
- blur mask
- undo stack
- redo stack
- sticker project

否则当前 localStorage 架构很容易容量爆掉。

后续如果需要保存可逆修图工程，再迁 IndexedDB。

八、CV 排版

最终排版：

CV 一条ひらめ
---------------- 虚线
Repo

要求：

- “CV”和填写的声优名在同一行
- 字号一致
- 两者颜色不同
  - CV：当前主题 accent / 粉色
  - 声优名：当前主题 ink / 深色
- 都使用粗体
- 不要把声优名放在“CV”下面

CV 下方：
一条很淡的主题色虚线，作为 Repo 区分隔。

九、RJ号

RJ号不占右侧信息区。

位置：
悬浮在 BK 右下角。

样式：
- 半透明白底
- 小圆角
- 主题深色字
- 字号约 10~12px
- 左对齐

宽度：
- 默认容纳 “RJ + 8位数字”
- 即正常 RJ 编号时不要留下明显多余空白
- 如果文本更长，再自适应扩展
- 设置合理 max-width，避免覆盖 BK 太多

重要：
RJ input / 数据即使“隐藏RJ号”也必须继续保留。
“隐藏”只影响模板预览/导出，不影响数据本身和自动导入功能。

十、一句话 Repo

位置：
右侧，CV 虚线下面。

样式继续保留当前轻便签风：
- 左侧细主题色竖线
- 左上小爱心
- 不做完整大圆角框
- 文字约 14~15px
- 2~3 行空间

不要：
- Repo 下方再加短实线
- 单独做第二个外框

卡片本身上下已有装饰线，Repo 下方短线已经删除。

十一、模板外工具栏

所有控制按钮都必须放在模板外。
不要进入 1080×1440 导出区域。

最终只保留三个，从左到右：

1. ☑ 显示RJ号
2. 按RJ号一键导入BK
3. 只清空Repo

不要：
- 清空全部
- 大标题输入
- 上一格 / 下一格
- 单独的工具栏 RJ 输入框

十二、“显示RJ号”

这是模板外的切换按钮。

开启：
- 12张 BK 上显示各自 RJ号

关闭：
- 预览隐藏
- 导出 PNG 也隐藏

但：
- 每格 RJ 数据仍保留
- 批量导入仍可以读取

文案：
☑ 显示RJ号
☐ 显示RJ号

十三、“按RJ号一键导入BK”

数据源：
读取 12 格各自保存的 RJ号。

不要再做一个额外 RJ 输入框。

点击后：
1. 扫描 12 格
2. normalizeWorkno()
3. RJ 为空 → 跳过
4. RJ 有效且 BK 为空 → 自动导入
5. RJ 有效且已经有 BK → 默认跳过
6. 单格失败 → 记录失败，但继续处理其他格
7. 最后反馈结果

建议反馈：
成功导入 X 张
X 格未填写 RJ
X 格导入失败

接口：
直接复用当前已有：
- fetchProductJson
- parseDlsiteProduct
- fetchImageAsPngDataUrl
- DLsite Worker proxy

并发建议：
一次 2~3 个请求，不要 12 个同时发。

十四、RJ 自动导入可以顺手填 CV

速评版字段里本身就需要：
- BK
- CV
- RJ

所以正式接入时建议：

根据 RJ 导入成功后：
- 自动填 BK
- 如果该格 CV 为空，同时自动填 CV

如果用户已经手填 CV：
默认不要覆盖。

十五、“只清空Repo”

只清空 12 个 review 字段。

不要清：
- BK
- CV
- RJ

用途：
用户可以保留一批作品，快速重新写一套速评。

十六、推荐数据结构

quickReview:
{
  showRj: true,
  cells: [
    {
      cover: "",
      coverFit: "cover",
      cv: "",
      rj: "",
      review: ""
    }
  ]
}

固定 cells 长度：12。

coverFit 推荐至少保存：
- contain = 完整
- cover = 裁切

这样“完整 / 裁切”切换可以被状态保存。

十七、导出 PNG

如果现有项目的速评版也采用 Canvas 手绘导出：
必须同步实现 DOM 预览的所有设计。

Canvas 需同步绘制：
- 2列 × 6行
- 单卡轻底色 / 圆角 / 轻描边
- 上下粉绿虚线
- 中央五角星
- 4:3 BK
- BK 白描边 + 轻阴影
- RJ右下悬浮
- CV同行双色
- CV下方虚线
- Repo 左侧竖线 + 小爱心
- 不画 Repo 底部短线

“显示RJ号=false”时：
Canvas 不画 RJ。

注意：
编辑工具条、上传按钮、模板下三个操作按钮都属于编辑 UI，
绝对不要进入导出 PNG。

十八、主题适配

不要把粉色/绿色写死。

尽量映射现有主题变量：
- accent
- accentDeep
- dash / mint
- ink
- muted
- line
- coverBg

装饰线：
左半跟 accent
右半跟 mint / dash

五角星：
上方可以 accent
下方可以 mint

不同色卡切换时，速评版应自动跟随主题。

十九、手机端

最终模板仍保持 1080×1440 比例。
手机只做整体缩放预览，不把 2×6 重排成单列。

需要重点保证：
- 手机点 BK 不误触 RJ input
- 点“上传”直接打开 file input
- 点已有 BK 主体显示工具条
- 工具条按钮触控区域不要太小
- 隐藏 RJ 后，“上传”按钮仍可显示
- 模板下三个按钮适配手机宽度

二十、这份 Demo 中哪些是参考、哪些不是正式功能

参考：
- 版式
- CSS装饰线
- 2×6结构
- BK尺寸与视觉
- CV / Repo 排版
- RJ位置
- PC / 手机工具条出现方式
- 模板外三个按钮位置

Demo 中未真正实现：
- 完整 / 裁切
- 正式修图
- 真实 DLsite 批量请求
- Canvas 导出

这些正式接入时应复用现有项目功能，不要照 Demo 的模拟代码重新造一套。

1. 模板名：速评版
2. 12条
3. 2列×6行
4. BK 4:3
5. 无大标题
6. RJ悬浮 BK 右下
7. RJ可全局隐藏

    ☑ 显示RJ号
